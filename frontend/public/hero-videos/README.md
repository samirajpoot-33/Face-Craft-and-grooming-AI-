# Hero background videos

Place **4 video files** here for the homepage hero carousel.

## Required files

Name your videos exactly:

- `video1.mp4`
- `video2.mp4`
- `video3.mp4`
- `video4.mp4`

## Format

- **Format:** MP4 (H.264 video, AAC audio recommended; audio is muted in the hero).
- **Aspect ratio:** 16:9 or similar landscape for best fit.
- **Length:** Short loops (e.g. 10–30 seconds) work well; they will loop automatically.
- **Size:** Prefer compressed files (e.g. under 5–10 MB each) for faster loading.

If you use different names or more/fewer videos, update the `videos` array in `frontend/src/components/Hero.jsx`.
