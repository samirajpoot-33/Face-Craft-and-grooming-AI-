# Makeup Steps Images

Add your three step images here:

1. **step1.jpg** - Image for Step 1 (Find Makeup Inspiration)
2. **step2.jpg** - Image for Step 2 (Upload Selfie & Reference)
3. **step3.jpg** - Image for Step 3 (Instant Makeup Replication)

## Image Requirements:
- Format: JPG or PNG
- Recommended size: 800x800px or larger (square aspect ratio)
- File names must be exactly: `step1.jpg`, `step2.jpg`, `step3.jpg`

## Alternative Location:
You can also add images to: `frontend/src/assets/makeup/steps/`
Then update the paths in `MakeupVirtualTry.jsx` to use imports instead.
